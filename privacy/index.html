Fonts are loaded from Google Fonts, and episode pages embed videos with YouTube's privacy-enhanced mode (youtube-nocookie.com); see the Google Privacy Policy.

Axon Orbit Uploader (Google API application)

"Axon Orbit Uploader" is a private tool used only by the owner of the Axon & Orbit YouTube channel to upload the channel's own videos through the YouTube Data API. It requests two permissions: uploading videos (youtube.upload) and reading the channel's own video list (youtube.readonly), which is used to confirm the connected channel and to build this website's episode list.

  • It accesses only the Axon & Orbit channel of the account that authorises it.
  • The authorisation token is stored only on the owner's own computers and private cloud environment. It is never shared, sold or transferred to third parties, and it is not used for advertising.
  • No data from other YouTube users is collected or stored.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service.
  • Access can be revoked at any time at myaccount.google.com/permissions.
